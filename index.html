Extracted Archives

Peat harvesting and data centres in Ireland, read side by side: how each industry takes from the land, what each keeps as an archive, and two futures drawn from those histories, one steeped in extraction and one built on balance.

The site is laid out like an atlas. Each page is a plate. Start with the map, move down through the bog and the data centre, then read the headlines and the working prototypes.
